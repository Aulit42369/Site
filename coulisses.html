// Coulisses techniques

Outils de stream sur mesure

Les outils qui tournent derrière le stream, construits sur-mesure plutôt qu'avec des solutions toutes faites — développés ici avec Claude. Comment ils sont pensés, et ce qu'il a fallu résoudre pour que ça marche.

// Régie Mobile

Piloter le stream depuis le téléphone

Gérer le stream sans être devant l'ordinateur : titre, catégorie et tags enregistrés sur Twitch, minuteur de démarrage qui lance scène et micro, pause pub programmable, grille de scènes OBS, modération du chat YouTube en direct, récompenses de points de chaîne. En fin de live, la carte « Raid · La Cabane » liste les membres de La Cabane en direct : même jeu d'abord, puis les plus petites chaînes. Un appui lance le raid, un autre l'annule.

Image d'annonce aux couleurs du site, publiée sur Instagram et Bluesky. Moniteur de santé qui fait vibrer le téléphone si le stream se dégrade, simulateur d'alertes, résumé de session en Excel. Les confirmations s'affichent dans la régie, plus dans les fenêtres du navigateur, et l'appli Android ne pèse plus qu'environ 700 Ko.

Le vrai défi : la confier à d'autres streamers sans rien leur ouvrir. La régie fabrique elle-même un kit (page /kit) qui ne contient que les réglages de la personne, aucun accès de la régie d'origine. Les mises à jour sont signées : publiées en un clic, elles apparaissent chez les autres dans un bandeau « Mise à jour disponible », s'installent sur un appui, se défont si besoin et ne touchent jamais aux données.

Distribuable en kit à d'autres streamers, avec mises à jour automatiques signées
Node.js · React · zéro dépendance · signature Ed25519 · Android

// twitch-alerts-bridge

Toutes les alertes, sans latence

Follows, subs, resubs, dons groupés, bits, raids, dons — un système bâti sur les webhooks EventSub de Twitch, avec ses propres sons synthétisés, un système anti-doublons et une file d'attente pour l'affichage dans l'overlay OBS.

Le plus dur n'a pas été le code mais le débogage : des redirections OAuth qui ne correspondaient pas, le pare-feu Windows qui bloquait des ports locaux, et un filtrage non documenté par Twitch qui ignore les follows de comptes trop récents.

Complété par un script Lua qui coupe l'écran de fin de raid automatiquement, avec délais réglables
Node.js · Twitch EventSub · OBS Lua

// labels-bridges

Le remplaçant maison de Stream Labels

Plutôt que de dépendre de Streamlabs, ces deux ponts (Twitch et YouTube) récupèrent les événements et les écrivent directement dans de simples fichiers .txt, lus par des panneaux HTML dans OBS.

Pas d'overlay complexe à charger, pas de service externe à surveiller — juste des fichiers texte relus à chaque changement. La solution la plus simple qui marche.

Intégré dans un overlay entièrement fait main — aucun asset ni template acheté, juste du code
Node.js · fichiers texte locaux

// Overlays & scripts OBS

Des scènes faites main, qui changent avec les saisons

Toutes les scènes du stream sont des pages web écrites maison et chargées dans OBS : une version de base et des versions festives ou saisonnières, avec les alertes et les labels intégrés directement dans l'overlay pour que tout reste uniforme. Le thème change à la main, par période, plutôt qu'à une date automatique.

Des scripts Lua pilotent OBS : un script de démarrage, un rafraîchissement des sources navigateur avec une case à cocher par source, et la coupure automatique de l'écran de fin de raid. Les mêmes éléments, anonymisés et documentés pas à pas, forment un kit réutilisable par quelqu'un qui débute.

Un « super dossier » de 11 dossiers numérotés rassemble tout l'environnement : site, widgets, overlays, ponts d'alertes et de labels, Régie Mobile, scripts Lua et panneaux
HTML · CSS · JavaScript · OBS Lua
// Carte à collectionner

Une extension Twitch multi-chaînes

Les viewers dépensent des points de chaîne pour ouvrir des packs de cartes à collectionner. Hébergée sur Render avec MongoDB Atlas, l'extension gère le français et l'anglais, des effets de cartes holographiques, un mode d'image pleine largeur, l'import de cartes en masse, et un bouton en libre-service pour que chacun supprime ses propres données.

Le morceau le plus coriace a été un problème de cache des sources navigateur OBS qui empêchait les nouvelles formes de pack de s'afficher correctement.

// Escape Fragments

Une escape room que le chat résout ensemble

Chaque viewer reçoit un fragment d'indice différent, et personne ne peut résoudre l'énigme seul : il faut mettre les indices en commun dans le tchat. Les fragments arrivent via une extension Twitch (le viewer partage son identité, sans rien taper), via la page joueur ou avec une commande dans le chat. Le serveur vérifie la signature Twitch de chaque viewer.

Autour du jeu : 27 scénarios dont 12 thématiques pour les fêtes du calendrier français, 28 thèmes visuels, une régie à onglets, un éditeur de scénarios avec aperçu en direct de l'overlay (couleurs, polices, image de fond), des profils d'agents avec classement, une télécommande installable sur téléphone et des annonces Discord. Chaque option — indices automatiques, mode traître, indice secret du streamer, mode versus, énigme entre streams — s'active depuis la régie.

Les cartes de résultat de fin de partie ne sont jamais publiées automatiquement : tout reste sous contrôle du streamer

// Jeux mobiles

Quatre jeux, jouables partout

LUMEN (un puzzle de fusion d'orbes), ÉCHO (un labyrinthe dans le noir), Résonance (un jeu d'ondes) et Fragments (un party game d'évasion sur plusieurs téléphones, tiré d'Escape Fragments). Chacun se joue dans le navigateur et s'installe comme une appli (PWA), avec une version Android native visant le Google Play Store.

Les quatre partagent un Défi du jour : la même partie pour tout le monde, qui change à minuit heure de Paris, avec une série de jours consécutifs. Le résultat se partage en texte ou en image au format story, et chaque jeu présente les trois autres. Chacun garde son dépôt et son domaine : seul le code du défi est commun, copié à l'identique dans les quatre.

ÉCHO parle 7 langues, Résonance 6, LUMEN et Fragments le français et l'anglais. Chaque jeu a sa page de confidentialité et de conditions d'utilisation.

// La Cabane

Le suivi des chaînes de la communauté

Le suivi existait d'abord dans un fichier Excel : Power Query pour récupérer followers et données de stream via l'API Twitch, une macro VBA pour les snapshots quotidiens, et des métriques SullyGnome ajoutées à la main — pas de scraping automatique, contraire à leurs conditions d'utilisation.

La Cabane en est la version web : un annuaire des streamers suivis (statut, rôle, historique de follows daté) et un pipeline de propositions où chaque chaîne passe par un vote du staff avant d'être acceptée. Les données vivent dans un dépôt privé ; un robot en tire une vitrine publique, sans aucune donnée interne, avec une page par streamer.

Les inscriptions aux événements passent par un relais Cloudflare : l'adresse secrète du salon Discord n'est plus dans la page publique. Un contrôle qualité Lighthouse tourne tout seul à chaque modification du site.

Volontairement séparée de la page Streamers de ce site — deux outils distincts, pas de pont entre les deux
Power Query · VBA · JSON · GitHub Actions · GitHub Pages · Cloudflare Workers

// Bot Discord

Le gardien du serveur d'entraide

Le bot qui fait tourner le serveur d'entraide entre streamers. L'entrée est filtrée : les nouveaux membres acceptent le règlement puis soumettent leur chaîne Twitch ou YouTube pour vérification avant d'obtenir l'accès complet — pas une communauté ouverte à tout le monde.

Au-delà de l'accueil : modération avec escalade automatique après plusieurs avertissements, anniversaires, sondages, salons vocaux temporaires, zone promo avec délai entre deux posts, annuaire des membres, tickets, concours, et annonces automatiques (chaînes suivies en direct, jeux gratuits, paliers de followers). Un panneau d'administration web permet de tout gérer sans passer par les commandes Discord.

Le bot tourne sur un Raspberry Pi, et l'adresse du tunnel vers son panneau peut changer, ce qui cassait les connexions Discord et Twitch. Un relais Cloudflare à adresse fixe, tenu à jour par le bot, renvoie maintenant toujours vers la bonne. Un tableau de santé privé, sur le téléphone, surveille le Pi, les bots, les sites et les sauvegardes, et prévient dans un salon Discord privé dès que quelque chose s'arrête.

Le même bot tourne aussi sur d'autres serveurs, avec des réglages propres à chacun
Discord · commandes slash · panneau d'admin web · Raspberry Pi · Cloudflare Workers

// Ce site

Un site qui se modifie sans code

Ce site est écrit en HTML, CSS et JavaScript simples, hébergé sur GitHub Pages, sans outil de build. Une page d'administration privée permet de tout changer depuis le navigateur : streamers, clips, planning (semaine type et changements ponctuels), À propos et FAQ, textes de chaque page, liens et bandeau d'annonce, nouvelles pages, liste des jeux. Chaque enregistrement devient une version sauvegardée, restaurable en un clic.

Des automatisations GitHub font le reste : statut Twitch (direct, abonnés, avatars), jeux récents, minification avec mise à jour du cache, vérification des liens et des données, tests dans un vrai navigateur et contrôle Lighthouse à chaque modification.

Côté visiteurs : pages Confidentialité et CGU, lecteurs Twitch chargés seulement après accord (ce sont eux qui déposent des cookies), données structurées pour Google, où les clips sont décrits comme des vidéos, et suivi dans la Search Console. Le site héberge aussi les mises à jour signées de la Régie Mobile.

Une règle maison : toute nouvelle page doit aussi être gérable depuis l'admin, et c'est vérifié automatiquement
