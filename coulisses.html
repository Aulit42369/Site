// Sous le capot

Coulisses techniques

Les outils qui tournent derrière le stream, construits sur-mesure plutôt qu'avec des solutions toutes faites — développés ici avec Claude. Comment ils sont pensés, et ce qu'il a fallu résoudre pour que ça marche.

// Régie Mobile

Piloter le stream depuis le téléphone

Une appli pour gérer le stream sans être devant l'ordinateur : changer de scène OBS, régler l'audio, publier sur Bluesky, modérer le chat YouTube en direct — chaque plateforme a son propre onglet d'événements.

Construite en Node.js et React sans aucune dépendance externe. Un système de nouvelles tentatives a été ajouté pour les cas où OBS met du temps à charger scènes et pistes audio, et la mise en page s'adapte aussi bien à un écran de bureau qu'à un téléphone.

Node.js · React · zéro dépendance
// twitch-alerts-bridge

Toutes les alertes, sans latence

Follows, subs, resubs, dons groupés, bits, raids, dons — un système bâti sur les webhooks EventSub de Twitch, avec ses propres sons synthétisés, un système anti-doublons et une file d'attente pour l'affichage dans l'overlay OBS.

Le plus dur n'a pas été le code mais le débogage : des redirections OAuth qui ne correspondaient pas, le pare-feu Windows qui bloquait des ports locaux, et un filtrage non documenté par Twitch qui ignore les follows de comptes trop récents.

Complété par un script Lua qui coupe l'écran de fin de raid automatiquement, avec délais réglables
Node.js · Twitch EventSub · OBS Lua
// labels-bridges

Le remplaçant maison de Stream Labels

Plutôt que de dépendre de Streamlabs, ces deux ponts (Twitch et YouTube) récupèrent les événements et les écrivent directement dans de simples fichiers .txt, lus par des panneaux HTML dans OBS.

Pas d'overlay complexe à charger, pas de service externe à surveiller — juste des fichiers texte relus à chaque changement. La solution la plus simple qui marche.

Node.js · fichiers texte locaux
// Carte à collectionner

Une extension Twitch multi-chaînes

Les viewers dépensent des points de chaîne pour ouvrir des packs de cartes à collectionner. Hébergée sur Render avec MongoDB Atlas, l'extension gère le français et l'anglais, des effets de cartes holographiques, un mode d'image pleine largeur, l'import de cartes en masse, et un bouton en libre-service pour que chacun supprime ses propres données.

Le morceau le plus coriace a été un problème de cache des sources navigateur OBS qui empêchait les nouvelles formes de pack de s'afficher correctement.

En cours : l'animation d'ouverture de pack dans l'overlay OBS
Extension Twitch · Render · MongoDB Atlas
