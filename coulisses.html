// Sous le capot

Coulisses techniques

Les outils qui tournent derrière le stream, construits sur-mesure plutôt qu'avec des solutions toutes faites — développés ici avec Claude. Comment ils sont pensés, et ce qu'il a fallu résoudre pour que ça marche.

// Régie Mobile

Piloter le stream depuis le téléphone

Gérer le stream sans être devant l'ordinateur : titre, catégorie et tags sauvegardés directement sur Twitch, minuteur de démarrage qui déclenche scène et micro à la fin, pause pub programmable, grille de scènes OBS, suggestions de raid dans la catégorie en cours, streamers suivis avec leur statut live, et gestion des récompenses de points de chaîne.

Un générateur d'image d'annonce reprend l'identité visuelle du site pour prévenir que le stream commence, avec publication directe sur Instagram et Bluesky. Un moniteur de santé (débit, FPS, images perdues, CPU OBS) fait vibrer le téléphone si ça dégrade, et un simulateur teste les alertes sans attendre un vrai événement. En fin de session, le résumé s'exporte en Excel.

Node.js · React · zéro dépendance

// twitch-alerts-bridge

Toutes les alertes, sans latence

Follows, subs, resubs, dons groupés, bits, raids, dons — un système bâti sur les webhooks EventSub de Twitch, avec ses propres sons synthétisés, un système anti-doublons et une file d'attente pour l'affichage dans l'overlay OBS.

Le plus dur n'a pas été le code mais le débogage : des redirections OAuth qui ne correspondaient pas, le pare-feu Windows qui bloquait des ports locaux, et un filtrage non documenté par Twitch qui ignore les follows de comptes trop récents.

Complété par un script Lua qui coupe l'écran de fin de raid automatiquement, avec délais réglables
Node.js · Twitch EventSub · OBS Lua

// labels-bridges

Le remplaçant maison de Stream Labels

Plutôt que de dépendre de Streamlabs, ces deux ponts (Twitch et YouTube) récupèrent les événements et les écrivent directement dans de simples fichiers .txt, lus par des panneaux HTML dans OBS.

Pas d'overlay complexe à charger, pas de service externe à surveiller — juste des fichiers texte relus à chaque changement. La solution la plus simple qui marche.

Intégré dans un overlay entièrement fait main — aucun asset ni template acheté, juste du code
Node.js · fichiers texte locaux

// Carte à collectionner

Une extension Twitch multi-chaînes

Les viewers dépensent des points de chaîne pour ouvrir des packs de cartes à collectionner. Hébergée sur Render avec MongoDB Atlas, l'extension gère le français et l'anglais, des effets de cartes holographiques, un mode d'image pleine largeur, l'import de cartes en masse, et un bouton en libre-service pour que chacun supprime ses propres données.

Le morceau le plus coriace a été un problème de cache des sources navigateur OBS qui empêchait les nouvelles formes de pack de s'afficher correctement.

En cours : l'animation d'ouverture de pack dans l'overlay OBS

// La Cabane

Le suivi des chaînes de la communauté

Le suivi existait d'abord dans un fichier Excel : Power Query pour récupérer followers et données de stream via l'API Twitch, une macro VBA pour les snapshots quotidiens, et des métriques SullyGnome ajoutées à la main — pas de scraping automatique, contraire à leurs conditions d'utilisation.

La Cabane en est la version web, avec deux vues : un annuaire des streamers suivis (statut, rôle, historique de follows daté, liens vers SullyGnome et TwitchTracker) et un pipeline de propositions où chaque chaîne passe par un vote du staff — pour, contre ou neutre — avant d'être acceptée. Les données vivent dans un dépôt privé séparé, seule la page de lecture publique est exposée sur GitHub Pages.

Volontairement séparée de la page Streamers de ce site — deux outils distincts, pas de pont entre les deux
Power Query · VBA · JSON · GitHub Pages

// Bot Discord

Le gardien du serveur d'entraide

Le bot qui fait tourner le serveur d'entraide entre streamers. L'entrée est filtrée : les nouveaux membres acceptent le règlement puis soumettent leur chaîne Twitch ou YouTube pour vérification avant d'obtenir l'accès complet — pas une communauté ouverte à tout le monde.

Au-delà de l'accueil, il couvre à peu près tout ce qu'un serveur actif demande : modération avec escalade automatique après un nombre d'avertissements, anniversaires, sondages à vote par boutons, salons vocaux temporaires créés à la demande, une zone promo avec délai minimum entre deux posts, un annuaire des membres, et des annonces automatiques (chaînes Twitch suivies qui passent en direct, jeux gratuits du moment, paliers de followers).
